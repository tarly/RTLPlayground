# ZX-SWTG024AS V0.2.2

## Changes

- Default hostname is the sticker model: `ZX-SWTG024AS`
- Login page and UI keep the stock RTLPlayground behaviour (the login page shows
  the hostname only after a successful login; a fresh browser still shows
  "Switch Login")
- LED colour order matches the enclosure: 2.5G green, 10/100/1000M amber
- Default network `192.168.10.247/24`, all ports VLAN1

## Firmware

`ZX-SWTG024AS-V0.2.2.bin`

- Size: 524288 bytes (512 KB)

## Behaviour

| Location | Before login | After login |
|---|---|---|
| UI top-left | - | `ZX-SWTG024AS` |
| Login page | `Switch Login` | `ZX-SWTG024AS` (from localStorage) |

## LED

| State | LED |
|---|---|
| 2.5G link | green |
| 1G / 100M / 10M link | amber |
| No link | off |
| SFP5 / SFP6 | single green |

Known hardware note: 1 amber and 2/4 green are dim on the tested unit.
Brightness is not individually controllable from the LED engine.

## Flashing

Use an external programmer: back up the current flash, write the 512 KB image,
verify, power on. Flash the first unit only until it validates.

## Verified

- 1-4 copper ports link and ping at 2.5G
- 1G shows amber, 2.5G shows green
- SFP5 / SFP6 link and pass traffic
- Web UI reachable, hostname shown as `ZX-SWTG024AS`
