# V0.2.1

## Goal

Fix the copper LED colour order for the ZX-SWTG024AS enclosure.

## Change

The RTLPlayground `SWTG024AS` 4+2 profile defines:

- green: 10M/100M/1G/10G
- amber: 2.5G

The enclosure of this unit defines the opposite:

- green: 2.5G
- amber: 10M/100M/1G

Only the first LED set (copper) was changed:

```text
LED0 (green): 2G5 + LINK + ACT
LED2 (amber): 10M + 100M + 1G + LINK + ACT + 10G
```

SFP set 1 remains single green. Port map, mux, SFP and network code are
unchanged.

## Result

- 1G → amber
- 2.5G → green
- SFP5/6 → single green
- no link → LEDs off

Known hardware note: 1 amber and 2/4 green are dim on this unit. The LED engine
has no per-LED brightness control.
