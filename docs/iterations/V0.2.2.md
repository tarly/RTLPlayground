# ZX-SWTG024AS V0.2.2

## 变更

- 默认 hostname 改为贴纸型号：`ZX-SWTG024AS`
- 登录页保持原 RTLPlayground 逻辑，不硬编码设备名
- LED 颜色维持 V0.2.1：2.5G 绿，10/100/1000M 橙
- 网络默认 `192.168.10.247/24`

## 名称行为

| 位置 | 来源 | 首次打开 | 登录后 |
|---|---|---|---|
| 主界面左上角 | `hostname` | - | `ZX-SWTG024AS` |
| 登录页标题/名称 | `localStorage.rtl_host` | `Switch Login` | `ZX-SWTG024AS` |

这与小米固件的行为一致：登录页只有在成功登录过一次后才会记住 hostname；换浏览器/清缓存后首次仍显示 `Switch Login`。

## 测试

1. 刷入；
2. 登录后看主界面左上角：应为 `ZX-SWTG024AS`；
3. 退出/重新打开登录页：应显示 `ZX-SWTG024AS`；
4. 清浏览器缓存后首次登录页仍显示 `Switch Login`，这是正常行为；
5. 1G 橙、2.5G 绿、SFP5/6 单绿。

## 小米固件检查

- `V0.2.6` 默认 config 没有 `hostname`，所以主界面左上角是 `RTLPlayground-XXXXXX`，不是 `SW-106T-A_XM`；
- `V0.2.6_configured4000` 里有 `hostname SW-106T-A_XM`，左上角才是硬件名；
- 两者的 `MACHINE_MODEL` 和 `MACHINE_PCB_INFO` 都是 `SW-106T-A_XM`，model/PCB 字符串一致；
- 如果希望小米默认版左上角也显示 `SW-106T-A_XM`，需要在默认 config 里补 `hostname SW-106T-A_XM` 后重编。
